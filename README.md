# Hosh_oof — هوش آفلاین

دستیار هوش مصنوعی آفلاین برای اندروید با رابط کاربری الهام‌گرفته از تجربه چت مدرن.

## هدف پروژه
- گفت‌وگوی متنی آفلاین با مدل زبانی اجراشده روی دستگاه
- تاریخچه و جست‌وجوی گفتگوها به‌صورت محلی
- انتخاب و تحلیل تصویر با مدل بینایی آفلاین
- ابزارهای نوشتن، ترجمه، خلاصه‌سازی و کمک برنامه‌نویسی
- ورود و خواندن فایل‌های متنی و PDF به‌صورت محلی
- معماری ماژولار برای افزودن مدل‌های تولید و ویرایش تصویر و قابلیت‌های صوتی
- رابط فارسی/انگلیسی، حالت تاریک/روشن و طراحی واکنش‌گرا

## اصل مهم آفلاین بودن
هسته برنامه نباید برای چت، تاریخچه یا پردازش فایل‌های محلی به سرور ابری وابسته باشد. مدل‌ها ممکن است جداگانه و با رضایت کاربر دریافت شوند؛ پس از نصب مدل موردنیاز، اجرای آن باید روی دستگاه انجام شود. دریافت مدل و به‌روزرسانی تنها قابلیت‌های اختیاری آنلاین هستند.

## محدودیت سخت‌افزاری
اجرای مدل‌های بزرگ، تحلیل تصویر و به‌ویژه تولید/ویرایش تصویر به RAM، فضای ذخیره‌سازی و توان پردازشی قابل‌توجه نیاز دارد. برنامه باید مدل‌های سبک را نیز پشتیبانی کند و پیش از دریافت مدل، حجم و حداقل نیاز سخت‌افزاری را نشان دهد.

## نقشه راه
1. ساخت پوسته اندروید و رابط چت
2. تاریخچه محلی، تنظیمات و مدیریت فایل
3. اتصال موتور اجرای مدل زبانی روی دستگاه
4. افزودن بینایی ماشین برای تحلیل عکس
5. افزودن مدل‌های اختیاری تولید/ویرایش تصویر
6. قابلیت‌های صوتی و ابزارهای تکمیلی
7. آزمون آفلاین، مصرف حافظه و پایداری

## وضعیت
شروع پروژه — پیاده‌سازی فنی هنوز در حال انجام است.
